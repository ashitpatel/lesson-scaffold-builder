```
==============================================================================
LESSON SCAFFOLD: Chapter 4 - Basic Hydrology Framework
==============================================================================
Goal: Students track local rainfall and calculate baseline local rainfall
figures over 4 weeks using class matrices.
Grade band: Middle. Period: 45 minutes.

UNIT                  WHAT IT IS
------------------------------------------------------------------------------
MLS-RAIN-01           Approving, Building and Placing Rain Containers (2
                      weeks). Starts fresh (no earlier unit needed).
MLS-RAIN-02           Recording Rainfall and Calculating the Baseline (4
                      weeks). Builds on MLS-RAIN-01.

Units that build on the same earlier unit, or start fresh, can run at the same
time.

The LSB framework functions purely as an adaptive, supportive scaffolding
framework for lesson content delivery. It does not prescribe operational
classroom routines, behavior management habits, or physical school rules.


==============================================================================
MLS-RAIN-01: Approving, Building and Placing Rain Containers
2 weeks. Starts fresh (no earlier unit needed).
==============================================================================
Goal: Puts approved rain containers in a secure spot and prepares the blank
class matrix, so the class can start recording rainfall.

WHO                   WHAT TO DO
------------------------------------------------------------------------------
1. Lead Educator      Ask the Community_Governance_Body to approve placing the
                      class rain containers in a secure spot on the school
                      grounds that is open to the sky. Confirm the approved
                      spot before any containers go outside.

2. Lead Educator      In class, explain that rainfall accumulation is the
                      depth of rain that collects in a container, measured in
                      millimetres. Cut each reused clear plastic bottle where
                      its sides become straight, turn the top upside down into
                      the bottle as a funnel, and cover every cut edge with
                      tape before handing the bottles to pairs. Students do
                      not handle the cutting blade.

3. Lead Educator      In class, pour clean water into each bottle until it
                      covers the uneven base and reaches the straight sides.
                      Pairs tape a paper strip down the side of each bottle,
                      mark 0 on the strip at that water line and mark
                      millimetres upward from it with a ruler. Then cover the
                      whole strip with clear tape.

4. Lead Educator      In class, pour more clean water into one finished bottle
[changed: EB-04]      so it stands a little above the 0 line, and show it to
                      each row. Every student writes the depth in millimetres
                      on scrap paper and holds it up at the same time. Look at
                      all the answers; if many are wrong, re-explain counting
                      millimetres up from the 0 line and repeat with a new
                      depth. Nothing is collected or recorded.

5. Lead Educator      Take the whole class together to the approved secure
                      spot and stay with all groups. Pairs set their
                      containers upright in the open, away from overhanging
                      cover. Place stones around each base yourself to hold it
                      steady. Students do not lift the stones.

6. Peer Facilitator   In class, student pairs draw the class matrix on chart
                      paper. Give it one row for each school day of the 4
                      weeks and one column for each container, with a weekly
                      total row after each week's last day.

------------------------------------------------------------------------------
BEFORE YOU START
- Needs: The Community_Governance_Body approves a secure spot for the
  containers within the unit's 2 weeks.
  If not: Build the containers and draw the matrix while waiting. If there is
  no answer by the end of week 2, follow up and ask which secure spot it will
  approve. Place the containers as soon as approval comes, and by week 4 at
  the latest. Start MLS-RAIN-02 only after placement. If there is still no
  approval by the end of week 4, close MLS-RAIN-01 with the containers kept in
  class, and start MLS-RAIN-02 only after approval and placement.
- Needs: Enough reused clear plastic bottles are available for one container
  per student pair.
  If not: Make fewer containers, with one per group of four or more students.
  Two containers are enough for the class matrix.
------------------------------------------------------------------------------
CHANGES FROM THE SOURCE
- Evidence-Based, EB-04 Checking for Understanding: after the scales are made,
  every student reads a sample depth onto scrap paper at once, and the
  educator looks at all answers and re-explains if many are wrong; nothing is
  collected


==============================================================================
MLS-RAIN-02: Recording Rainfall and Calculating the Baseline
4 weeks. Builds on MLS-RAIN-01.
==============================================================================
Goal: Fills the class matrix with 4 weeks of rainfall readings and turns them
into the class's baseline rainfall figures.

WHO                   WHAT TO DO
------------------------------------------------------------------------------
1. Lead Educator      Recall from MLS-RAIN-01: use the placed rain containers
                      and the blank class matrix on chart paper. Set a rota on
                      the chart so each student pair reads one container on
                      given days.

2. Lead Educator      On the last school day before the 4 weeks of readings
                      begin, at reading time, the whole class goes together to
                      the containers and the educator stays with all groups.
                      The educator empties and refills each container to the 0
                      line, so the 4 weeks of readings cover 28 days. Students
                      do not drink the water, lift the containers or touch the
                      stones. Recording starts on the first school day of the
                      4 weeks.

3. Peer Facilitator   Each school day at the same time, the whole class goes
                      together to the containers, and the educator stays with
                      all groups. The rota pair reads the water depth in
                      millimetres on the scale and calls it out for others to
                      check. The educator then empties each container and
                      refills it to the 0 line from a bottle of clean water
                      brought from class. Students do not drink the water,
                      lift or move the containers, or touch the stones.

4. Peer Facilitator   Back in class, the rota pair writes each container's
                      reading in that day's row of the class matrix. Write 0
                      on dry days.

5. Lead Educator      At the end of each week, lead the class in adding each
                      container's daily readings and writing the results in
                      the weekly total row of the class matrix.

6. Lead Educator      On the last school day, in a separate time block after
[changed: EB-03]      that day's reading and weekly total, give a full lesson
                      on baseline figures. On the board, work one example step
                      by step using three containers' made-up weekly totals:
                      total each container's weeks, average those totals (skip
                      containers missing a reading), then divide by 4 weeks
                      and by 28 days for the weekly and daily averages. Then
                      each student calculates the class's figures in their
                      notebook from the matrix.

7. Lead Educator      At the end of that lesson, lead the class in comparing
[changed: EB-03]      their results and writing the agreed baseline figures on
                      chart paper.

------------------------------------------------------------------------------
BEFORE YOU START
- Needs: Some rain falls during the 4 weeks.
  If not: Keep recording 0 on dry days. Zero readings are valid data, and the
  baseline figures are still calculated from them.
- Needs: All 4 weeks are school weeks with daily access to the containers.
  If not: If a week is lost to a holiday or closure, take readings for the
  remaining 3 weeks and draw a line through the lost week's rows. On the first
  day back, the educator empties and refills each container to the 0 line
  without recording, and readings start again the next school day. Do steps 6
  and 7 in the last periods of the final week and calculate over 3 weeks
  instead of 4. Divide by the number of weeks and the number of days actually
  covered by the recorded readings.
- Needs: The containers stay upright and in place between readings.
  If not: Mark that container's reading for the day as missing on the matrix
  and use the other containers for that day. The educator resets the container
  and refills it to the 0 line at the next visit.
------------------------------------------------------------------------------
CHANGES FROM THE SOURCE
- Evidence-Based, EB-03 Worked Examples, then Practice: one complete worked
  example with made-up totals is shown step by step on the board before each
  student calculates the class's own baseline figures in their notebook. The
  lesson is set on the last school day, in a separate time block after that
  day's reading and weekly total, so it works from the complete matrix within
  the 4 weeks. The full lesson, the missing-reading rule and the ÷ 4 and ÷ 28
  steps are kept.
- Evidence-Based, EB-03 Worked Examples, then Practice: the comparison of
  results is placed at the end of the step 6 lesson, so the worked-example
  lesson and its follow-up fit the declared weeks (EB-G6); the action itself
  is unchanged
```
