==============================================================================
LESSON SCAFFOLD: Chapter 4 - Basic Hydrology Framework
==============================================================================
Goal: Track local rainfall across seasons to calculate baseline regional
parameters over 4 weeks using class matrices.
Grade band: Middle. Period: 45 minutes.

UNIT                  WHAT IT IS
------------------------------------------------------------------------------
MLS-HYDRO-01          Placing Containers and Recording Rainfall Accumulation
                      (2 weeks). Starts fresh (no earlier unit needed).
MLS-HYDRO-02          Calculating Baseline Regional Parameters from Class
                      Matrices (2 weeks). Builds on MLS-HYDRO-01.

Units that build on the same earlier unit, or start fresh, can run at the same
time.

The LSB framework functions purely as an adaptive, supportive scaffolding
framework for lesson content delivery. It does not prescribe operational
classroom routines, behavior management habits, or physical school rules.


==============================================================================
MLS-HYDRO-01: Placing Containers and Recording Rainfall Accumulation
2 weeks. Starts fresh (no earlier unit needed).
==============================================================================
Goal: Builds the trusted weekly class totals of rainfall accumulation that the
baseline calculation needs.

WHO                   WHAT TO DO
------------------------------------------------------------------------------
1. Lead Educator      Get approval from the Community_Governance_Body through
                      the Dorbar Shnong, as is customary in Khasi villages to
                      place reused bottles in two secure spots on school
                      grounds. Explain rainfall accumulation as the depth of
                      rain collected in a bottle. Go outside with the whole
                      class together and stay with all groups to mark the
                      spots with the class using chalk and string.

2. Lead Educator      Go outside with the whole class together and stay with
                      all groups to place one reused bottle in each marked
                      spot. Show how to set each bottle upright and mark the
                      starting line with chalk, choosing large jars that will
                      not overflow in heavy Mawsynram rain. Students must not
                      pick up or move bottles after placement and must not
                      drink the collected water.

3. Lead Educator      Go outside with the whole class together and stay with
[changed: EB-04]      all groups to read the water level in each bottle
                      against the chalk mark. Have every student write each
                      reading on scrap paper and hold it up, look at all
                      answers, and re-explain reading against the chalk mark
                      if many are wrong. Record the two readings as class
                      totals on chart paper using a class table. Students must
                      not lift full bottles and must not drink the collected
                      water.

4. Peer Facilitator   In mixed pairs with two rotating roles, Checker and
[changed: CL-02]      Adder, swapping roles each day, check the class table on
                      chart paper for missing daily readings, noting both
                      morning and evening readings in monsoon and fill gaps
                      from the agreed bottle. Add each day to a running class
                      total for the week. Use only class totals, not names or
                      home details.

5. Lead Educator      In week 2, ask three short questions on scrap paper from
[changed: EB-01]      memory with chart and notebooks put away about bottle
                      starting line, reading against the chalk mark, and
                      adding daily totals. Then show the answers on the board
                      so each student checks their own. Nothing is collected
                      or marked.

------------------------------------------------------------------------------
BEFORE YOU START
- Needs: School grounds accessible for short visits and reused bottles, chalk,
  string and chart paper available.
  If not: If grounds are closed or rain fails for a week, combine two daily
  readings into one period and drop the second bottle spot, keeping the unit
  within 2 weeks.
------------------------------------------------------------------------------
CHANGES FROM THE SOURCE
- Evidence-Based, EB-04 Checking for Understanding: every student shows each
  bottle reading during teaching and the educator re-explains if many are
  wrong
- Evidence-Based, EB-01 Retrieval Practice: low-stakes recall of starting
  line, reading, and totalling steps from memory in week 2, self-checked
- Connected Learning, CL-02 Structural Peer Roles: teacher-only checking and
  totalling done in mixed pairs with rotating Checker and Adder roles


==============================================================================
MLS-HYDRO-02: Calculating Baseline Regional Parameters from Class Matrices
2 weeks. Builds on MLS-HYDRO-01.
==============================================================================
Goal: Turns the weekly class totals into the baseline regional parameter that
answers the chapter goal.

WHO                   WHAT TO DO
------------------------------------------------------------------------------
1. Lead Educator      Recall from MLS-HYDRO-01: use the weekly class totals of
[changed: EB-04]      rainfall accumulation from the chart paper table.
                      Explain baseline as the average weekly accumulation over
                      four weeks and copy the weekly totals into a new class
                      matrix on chart paper. Every student writes the baseline
                      meaning on slates and holds it up, the educator looks at
                      all slates and re-explains if many are wrong before
                      moving on.

2. Lead Educator      Show one complete worked example on the board adding the
[changed: EB-03]      weekly totals and dividing by the number of weeks step
                      by step, saying each step aloud. Then give a full lesson
                      of quiet working time for each student to add the weekly
                      totals and divide by the number of weeks in their
                      notebook to write the baseline value and one sentence
                      explaining what it shows about local rainfall. Use only
                      class totals and reused chart paper.

3. Lead Educator      Check each baseline calculation against the class matrix
                      on chart paper. Write one note on each notebook about a
                      missing step or unclear sentence. Return notebooks for
                      correction.

4. Lead Educator      Lead the class to agree the final baseline regional
                      parameter and write it as a class total on chart paper.
                      Compare the four weekly totals to the baseline in one
                      sentence on the chart, linking the result to
                      roof-catchment runoff seen in the Khasi hills. Keep the
                      chart for seasonal tracking.

------------------------------------------------------------------------------
BEFORE YOU START
- Needs: Classroom time for matrix work with chart paper and notebooks
  available.
  If not: If a week is lost, combine the check and correction steps into one
  period and shorten writing time to one sentence, keeping the unit within 2
  weeks.
------------------------------------------------------------------------------
CHANGES FROM THE SOURCE
- Evidence-Based, EB-04 Checking for Understanding: every student answers
  baseline meaning on slates at once, educator looks at all answers and
  re-explains if many are wrong
- Evidence-Based, EB-03 Worked Examples, then Practice: complete worked
  addition-and-division example shown step by step before the same solo
  baseline calculation
