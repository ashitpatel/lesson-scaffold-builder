```
==============================================================================
LESSON SCAFFOLD: History Grade 8 - Block 3: Migration Stories, Past and
Present
==============================================================================
Goal: Students explain migrations with push and pull factors, using historical
sources as evidence.
Grade band: Middle. Period: 45 minutes.

UNIT                  WHAT IT IS
------------------------------------------------------------------------------
MLS-MIGR-01           Push and Pull Factors and Large Movements (2 weeks).
                      Starts fresh (no earlier unit needed).
MLS-MIGR-02           Reading Sources and Building a Migration Timeline (3
                      weeks). Builds on MLS-MIGR-01.
MLS-MIGR-03           Explaining One Migration with Evidence (3 weeks). Builds
                      on MLS-MIGR-02.

Units that build on the same earlier unit, or start fresh, can run at the same
time.

The LSB framework functions purely as an adaptive, supportive scaffolding
framework for lesson content delivery. It does not prescribe operational
classroom routines, behavior management habits, or physical school rules.


==============================================================================
MLS-MIGR-01: Push and Pull Factors and Large Movements
2 weeks. Starts fresh (no earlier unit needed).
==============================================================================
Goal: Builds the push and pull vocabulary and the four large movements that
later units use to read sources and explain one migration.

WHO                   WHAT TO DO
------------------------------------------------------------------------------
1. Lead Educator      Ask why lack of work would drive people away and why
[changed: EB-09]      work elsewhere would draw people in, with each student
                      writing one line for each from the guide, then state
                      that lack of work is a push factor and work elsewhere is
                      a pull factor. Explain push factors and pull factors
                      with two examples of each from the guide, including the
                      Famine and coffin ships among them. Students copy the
                      definitions and the four examples into their notebooks.

2. Lead Educator      Draw a simple route map on the board for four large
                      movements: the early peopling of Europe, arrivals from
                      North America from the 1500s to the 1800s, moves to
                      Dublin during the 1900s, and moves from County Kerry to
                      Belfast. Students copy the dates and routes from the
                      board into their notebooks.

3. Lead Educator      Ask each student to write in their notebook two push
[changed: CL-04]      examples and two pull examples taken from the four
                      movements on the board. Collect one example from each
                      student to build a class chart of push and pull factors
                      on chart paper, without names or marks attached, for use
                      in later lessons.

4. Lead Educator      Call out each of the four movements in turn and ask
[changed: EB-04]      every student to write one push factor and one pull
                      factor for it on scrap paper and hold it up at the same
                      time. Look at all the answers and re-explain any
                      movement where many are wrong before moving on,
                      correcting answers on the board.

------------------------------------------------------------------------------
BEFORE YOU START
- Needs: Board, chalk and student notebooks are available.
  If not: If one session is lost, combine steps 3 and 4 in one period and keep
  the unit at 2 weeks.
------------------------------------------------------------------------------
CHANGES FROM THE SOURCE
- Evidence-Based, EB-09 Elaborative Interrogation: telling of push and pull
  becomes asking precise why questions attempted first, then stating the
  precise answers
- Evidence-Based, EB-04 Checking for Understanding: volunteer answers become
  every student answering at once on scrap paper with educator review and
  re-explanation
- Connected Learning, CL-04 Collective Shared Purpose: individual push/pull
  examples combined into a nameless class chart for later use


==============================================================================
MLS-MIGR-02: Reading Sources and Building a Migration Timeline
3 weeks. Builds on MLS-MIGR-01.
==============================================================================
Goal: Turns the push and pull vocabulary into source evidence by reading three
textbook sources and recording five dated migration events with their factors.

WHO                   WHAT TO DO
------------------------------------------------------------------------------
1. Lead Educator      Recall from MLS-MIGR-01: use the class chart of push and
                      pull factors. Read aloud the 1945 farm worker letter
                      from the textbook, mentioning remittances sent home to
                      family. Students write in notebooks who wrote it, when,
                      why, and which push and pull factors it shows.

2. Lead Educator      Read aloud the 1960 newspaper report on families
[changed: EB-09]      arriving in Dublin. Ask why families moved to the
                      capital and have students write in notebooks who wrote
                      it, when, why, and which push and pull factors it shows.
                      Then state the precise push and pull answers from the
                      report.

3. Lead Educator      Read aloud the song verse about leaving home from the
                      textbook, like an emigration ballad sung at an American
                      wake. Students write in notebooks who created it, when,
                      why, and which push and pull factors it shows.

4. Lead Educator      Give each student a long strip of paper marked 1900 to
[changed: CL-02]      today. In mixed pairs, one student reads an event with
                      its push and pull factors aloud from the notes while the
                      other marks it on their own strip, then they swap roles
                      for each event until each strip shows five events with
                      one push factor and one pull factor under each.

5. Lead Educator      In week 3, open a lesson with four short questions on
[changed: EB-01]      push and pull factors and timeline events, answered from
                      memory on scrap paper with the chart, notebooks and
                      textbook put away. Show the answers straight after so
                      each student checks their own. Nothing is collected or
                      marked.

6. Lead Educator      Ask each pair to call out one event from their strips
[changed: CL-04]      and add it to one class timeline on the board with one
                      push factor and one pull factor under each event. Show
                      only events and factors with no names, scores or marks.

------------------------------------------------------------------------------
BEFORE YOU START
- Needs: Textbook copies of the three sources and long strip paper for
  timelines are available.
  If not: If strip paper is short, join notebook pages into one strip; if one
  week is lost, read two sources in one week and drop the second timeline
  period, keeping the unit at 3 weeks.
------------------------------------------------------------------------------
CHANGES FROM THE SOURCE
- Evidence-Based, EB-09 Elaborative Interrogation: turned telling into
  asking-then-telling: students attempt why families moved before the precise
  push and pull answers are stated
- Evidence-Based, EB-01 Retrieval Practice: low-stakes recall of factors and
  timeline events from memory in week 3, self-checked
- Connected Learning, CL-02 Structural Peer Roles: timeline marking done in
  mixed pairs with reader and marker swapping each event, each student still
  makes their own strip
- Connected Learning, CL-04 Collective Shared Purpose: individual strips
  combined into one class timeline on the board with no names or scores


==============================================================================
MLS-MIGR-03: Explaining One Migration with Evidence
3 weeks. Builds on MLS-MIGR-02.
==============================================================================
Goal: Produces each student's own two-page explanation of one timeline
migration with push and pull factors, two sources, and one change to the place
left.

WHO                   WHAT TO DO
------------------------------------------------------------------------------
1. Lead Educator      Recall from MLS-MIGR-02: use the timeline and the three
                      source notes. Each student chooses one migration from
                      the timeline and writes in their notebook which two
                      sources they will use, which push and pull factors
                      explain it, and one way it changed the place people
                      left, such as empty cottages or quiet villages.

2. Lead Educator      Give a full lesson of quiet writing time. Each student
                      drafts a two-page explanation of the chosen migration
                      that explains its push and pull factors using at least
                      two sources and the timeline.

3. Lead Educator      Give a second full lesson of quiet writing time for each
                      student to complete the two-page draft, including one
                      way the migration changed the place people left.

4. Peer Facilitator   In pairs, read each other's draft and check it against
                      the push and pull factors, the two sources, and the
                      change to the place left. Each partner writes one note
                      on what is missing or unclear, then partners swap roles.

5. Lead Educator      Give a final lesson for each student to revise the draft
                      using the partner's note and write a final copy in their
                      notebook.

6. Lead Educator      Place a sheet of chart paper on the board with columns
[changed: CL-04]      for migration, one push factor and one pull factor, with
                      the educator present in the classroom. Each student who
                      wishes to take part adds one line for the migration
                      explained, without names or marks. Read the finished
                      class table together.

------------------------------------------------------------------------------
BEFORE YOU START
- Needs: Notebooks and quiet class time for drafting and revising are
  available.
  If not: If one session is lost, combine the two drafting lessons into one
  longer writing period plus notebook completion, keeping the unit at 3 weeks.
------------------------------------------------------------------------------
CHANGES FROM THE SOURCE
- Connected Learning, CL-04 Collective Shared Purpose: one-line class table
  built from each student's final explanation
```
