*Part 6 of 6 in a series on [Lesson Scaffold Builder](https://github.com/ashitpatel/lesson-scaffold-builder).*

This tool is not an authority, and it shouldn't be the last word on any school's lessons. It is a working prototype: it runs end to end, it has been run on nine test lessons, and **no teacher or curriculum specialist has reviewed its output yet**. Nothing here shows the cards improve learning. The list of teaching methods is a project choice that needs review by the people who own the content. Read everything it makes as a first draft for a teacher's judgment.

That said, it is free, open source, and built to be adapted. Three ways to use it, from easiest to fullest.

## 1. As a chat, no setup

Open it in [ChatGPT]({{ site.data.try_links.chatgpt }}), [Claude]({{ site.data.try_links.claude }}) or [Google AI Mode]({{ site.data.try_links.google_ai_mode }}). Each link starts a new chat with a condensed prompt already filled in: the role, the limits, all fifteen methods in one line each, and the seven questions from [part 2]({{ site.baseurl }}/seven-questions/). Paste a lesson when it asks. ChatGPT and AI Mode work without an account; AI Mode isn't offered in every country.

The shorter prompt carries less detail, and a chat can't run the code checks — the unit and step limits, the region-specific term lists, the 21-check review. If the chat drifts out of role in a long session, paste the prompt again.

## 2. The full pipeline, free, in a browser

For the complete run — code checks, independent review, repair rounds, printed cards — you need a free Gemini key from [Google AI Studio](https://aistudio.google.com/apikey) (no billing) and a notebook at [Google Colab](https://colab.research.google.com). Clone the repository, install two Python libraries, set the key, and run one command on a lesson. The [README](https://github.com/ashitpatel/lesson-scaffold-builder#2b-no-terminal-run-the-full-pipeline-in-the-browser-free-needs-a-key) walks through it step by step. On your own computer, the same command runs through a Claude Code or Muse login instead, with no key.

## 3. Rebuild it or adapt it

The prompts that built the project are public: every stage's regeneration prompt is in [docs/regeneration-prompts.md](https://github.com/ashitpatel/lesson-scaffold-builder/blob/main/docs/regeneration-prompts.md). The method cards live in [frameworks/](https://github.com/ashitpatel/lesson-scaffold-builder/tree/main/frameworks), the fifteen checks' evidence requirements beside them. Anyone can rebuild the pipeline, check it, translate the cards, swap the method list for their curriculum's own, or retune the limits (units, steps, weeks) for their timetable.

## What would help most

- **A teacher reading one [walkthrough](https://github.com/ashitpatel/lesson-scaffold-builder/tree/main/docs/walkthroughs)** in their subject and saying what's wrong with the cards.
- **A curriculum specialist reviewing the method list** — especially the five evidence-based practices.
- **A run on a real lesson** in your system, and a note on where the removals or additions misfired.

Corrections and reports are welcome as [issues](https://github.com/ashitpatel/lesson-scaffold-builder/issues). The series starts [here]({{ site.baseurl }}/from-lesson-to-classroom/).
